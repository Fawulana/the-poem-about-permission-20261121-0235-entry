A short poem about agency — the power to ask and to be given, handed over, and taken back.

`main.ts` (Node 22, stdlib only, no network) writes the fixed poem to `/output/entry.txt`. It runs twice and writes identical bytes both times.

## Run

```sh
node main.ts
cat /output/entry.txt
```
